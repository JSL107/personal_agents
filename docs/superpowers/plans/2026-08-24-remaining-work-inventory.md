## 어떻게 판정했나 (재현 가능하게)

앞 문서와 같은 3단계를 그대로 썼다. 문서가 아니라 코드·PR·파일 존재를 근거로 삼는다.

1. **기능 존재** — 주제어로 `src/` 와 `clients/` 를 grep. 못 찾은 것과 없는 것은 다르다.
   찾지 못했으면 "미구현" 이 아니라 "미확인" 으로 적고 확인 방법을 함께 남긴다.
2. **브랜치 머지 여부** — `gh pr list --head <branch> --state all`. 커밋 수로 판정하지 않는다.
3. **에셋·스프라이트** — 파일이 `Resources/raw/` 에만 있고 `Resources/sprites/` 와 Swift 참조가
   비어 있으면 "생성했지만 연결 안 됨" 이다. 두 곳을 함께 봐야 한다.

## 3. 진짜 남은 것 — 고쳐야 하는 것

### 3-1. 만료된 승인 카드가 연동 레코드를 `PENDING` 으로 남긴다

`expire-previews.usecase.ts` 는 카드 상태를 `EXPIRED` 로 바꾸고 이벤트를 쏘지만
(`:48-57`), 취소 처리기(canceller)를 부르지 않는다. `src/preview-gate` 전체에 canceller
호출이 없다. 사람이 ✅ 도 ❌ 도 누르지 않고 시간이 지나면 연동 레코드가 영구히 `PENDING` 으로
남는다. 카드 결말의 다수가 만료라는 점을 감안하면 실제로 쌓이고 있을 가능성이 높다.

앞 문서에도 있던 항목이며 **11일이 지나도 그대로다.**

### 3-2. `state.changed` 이벤트가 말풍선 문구를 싣지 않는다

`console.type.ts:129-132` 의 payload 는 `agentType` 과 `state` 뿐이다. 문구는 스냅샷에만 있어,
화면이 상태 변경 직후 스냅샷을 한 번 더 당겨오는 방식으로 우회하고 있다. 근본 수정은 백엔드
이벤트 계약 변경이라 PR #276 에서 답변만 남기고 분리했다.

### 3-3. `character-e` 스프라이트가 연결되지 않았다

`Resources/raw/character-e.png` 는 있으나 `Resources/sprites/` 에 나온 결과물이 없고 Swift
참조도 0건이다. 당시 사용자 요청으로 Swift 수정 3곳을 원복하면서 에셋과 Python 생성 매핑만
남았다. 쓸지 버릴지 판정이 필요하다.
