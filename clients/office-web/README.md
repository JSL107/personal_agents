# 이대리 오피스 — 웹 렌더러 · 윈도우 앱

맥이 계산한 사무실 배치를 받아 **브라우저 Canvas 로 그리는** 화면. 화면 전송이 아니라
그림을 이쪽에서 직접 그리므로, 같은 코드를 Electron 으로 포장해 **윈도우 PC 에 설치**한다
(→ [윈도우 PC 에 설치하기](#윈도우-pc-에-설치하기)). 맥은 데이터만 주고 그림은 윈도우가 그린다.

## 브라우저로 띄우기

```bash
# 1. 평면도를 뽑는다 (백엔드가 켜져 있어야 한다 — 사람이 0명이면 좌석도 0개다)
cd ../idaeri-console
for cols in 3 2; do
  IDAERI_CONSOLE_URL=http://127.0.0.1:3099 \
    .build/arm64-apple-macosx/debug/IdaeriConsole \
    --layout-json ../office-web/layout-$cols.json --zone-columns $cols
done

# 2. 서버를 띄운다 (정적 파일 + /v1/* 를 백엔드로 넘기는 프록시)
cd ../office-web
IDAERI_CONSOLE_URL=http://127.0.0.1:3099 python3 serve.py 8777
```

http://127.0.0.1:8777 을 연다.

> **백엔드 주소는 맥 앱과 같은 규칙**(`IDAERI_CONSOLE_URL`, 기본 `127.0.0.1:3002`)을 쓴다.
> 실운영은 `3099` 라 위 예시가 그 값을 지정한다 — 맥 앱을 띄울 때도 같은 값을 준다.
> 포트가 어긋나면 `/v1/*` 가 502 로 떨어지고, 어느 주소를 두드렸는지 응답에 함께 나온다.

## 평면도를 다시 뽑아야 할 때

`layout-*.json` 은 **스냅샷 시점의 사진**이다. 사람이 늘거나 줄면, 부서 편성이 바뀌면,
배치 규칙이나 에셋이 바뀌면 다시 뽑아야 한다. 상태(무슨 일이 도는지)는 실시간으로 받으므로
다시 뽑을 필요가 없다.

## 윈도우 PC 에 설치하기

브라우저 대신 **설치 파일(.exe)** 로 만든다. `serve.py` 가 하던 프록시 역할은 Electron 메인
프로세스(`main.js`)가 맡는다 — 창을 loopback 서버에 붙이므로 `live.js` 의 `fetch`·`EventSource`
가 개발 때와 **같은 코드로** 돈다(브라우저 출처 제약을 끄지 않는다).

```bash
# 평면도를 먼저 뽑는다 — 위 「브라우저로 띄우기」 1번과 같은 명령이다
cd clients/office-web
pnpm install

pnpm start      # 맥에서 그대로 띄워 본다
pnpm dist:win   # dist/IdaeriOfficeSetup-<버전>.exe 를 만든다
```

만든 `.exe` 를 윈도우 PC 로 옮겨 실행한다(`dist/` 는 저장소에 올리지 않는다).

`pnpm dist:win` 은 평면도가 없으면 빌드 전에 끊는다 — 없는 채로 만들면 **텅 빈 사무실이
설치되고**, 그게 "백엔드가 꺼져 있다" 와 구별되지 않는다.

### 첫 실행

설정 화면이 먼저 열린다. 맥의 주소를 넣는다.

| 어디서 보나 | 주소 |
|---|---|
| 같은 공유기 | 맥의 내부 주소 `192.168.x.x:3099` (맥에서 `ipconfig getifaddr en0`) |
| 밖에서 | Tailscale 주소 `100.x.x.x:3099` |

`http://` 는 빼도 붙여 준다. 저장하면 그 주소를 실제로 찔러 보고 **사무실에 몇 명 있는지**
보여준다 — 못 닿으면 이유를 알려주되 주소는 저장한다(맥이 그저 꺼져 있을 수도 있다).
나중에 주소를 고치려면 **사무실 → 서버 설정**(`Ctrl+,`).

토큰 칸은 지금 **효력이 없다** — 백엔드의 읽기 경로가 토큰을 검사하지 않는다
(`src/console/interface/console-write.guard.ts` 는 write 전용). 미리 넣어 두면 서버를 잠그는
날 앱을 다시 깔지 않아도 된다.

### 평면도는 빌드에 동봉된다

`layout-*.json` 을 앱 안에 넣어 내보낸다. 좌석 배치의 입력은 백엔드 코드의
`AGENT_REGISTRY`(에이전트 목록 상수)라, 평면도가 바뀌는 계기는 "그 목록이 바뀔 때" =
어차피 앱을 다시 만드는 때다. 서버에서 받아오게 만들면 코드만 늘고 **맥에서 평면도를 뽑는
수동 절차는 그대로 남는다.**

앱이 옛 평면도를 들고 있는데 백엔드에 사람이 늘면 그 사람은 자리를 못 찾는다. 그때는 상태
줄이 붉게 바뀌며 **누가 자리를 못 찾았는지 이름을 찍는다** — 자리 없는 사람은 화면에서
오류 없이 사라지므로, 그 표시가 없으면 아무도 모른다.

### 알아 둘 것

- 설치본은 **x64** 로 고정해 만든다(`build.win.target[].arch`). 맥에서 그냥 빌드하면 호스트를
  따라 **ARM64 가 나오고 일반 윈도우 PC 에서는 설치가 안 된다.** Windows on ARM 은 x64 를
  에뮬레이션하므로 x64 하나로 두 경우를 덮는다.
- 코드 서명을 하지 않아 설치할 때 **"알 수 없는 게시자"** 경고가 뜬다. 개인용이라 그대로 쓴다.
- 맥이 켜져 있고 백엔드(3099)가 떠 있어야 한다. 앱은 화면만 그린다.
- `pnpm start` 가 `ELECTRON_RUN_AS_NODE` 를 지우고 electron 을 부르는 이유는, 그 환경변수가
  붙어 있으면 electron 이 **창 없는 순수 Node 로 떠** `require("electron")` 이 빈 값을 준다.
  에디터의 통합 터미널에서 물려받는 경우가 있어 스크립트에서 끊어 둔다.

### 눈으로 확인하기

```bash
pnpm capture   # 사무실을 한 판 그려 /tmp/idaeri-office.png 로 저장하고 끝난다
```

맥 앱의 `--render`, 웹의 `?static=1` 과 같은 자리다. 다 그리지 못하면 **exit 1** 로 끊고 상태
줄을 함께 찍는다 — 스프라이트 경로가 어긋나거나 스냅샷을 못 받으면 창이 조용히 비는데,
그걸 성공으로 넘기지 않기 위한 입구다.

## 확인용 입구

| URL | 무엇 |
|---|---|
| `?static=1` | 한 판만 그리고 멈춘다. 화면 캡처 도구용 — 실시간 스트림을 열면 페이지가 "다 실렸다"에 도달하지 않아 캡처가 영영 기다린다 |
| `?hour=12` | 창밖 빛을 그 시각으로 고정. 맥 앱의 `--render --hour` 와 같은 화면을 만든다 |
| `?walk=3` | 산책을 강제로 일으키고 그 초만큼 진행시킨 뒤 그린다. 걷기는 시간이 지나야 나타나 정지 화면에 안 잡힌다 |

맥 앱과 대조하려면 두 화면을 같은 크기로 맞춘다 — 캔버스는 창에서 가로 24px·세로 52px 을
뺀 크기이므로, `--size 1400x820` 에 맞추려면 브라우저 창을 1424×872 로 연다.

## 배치 규칙을 여기서 다시 짜지 않는다

좌석이 한 칸이라도 어긋나면 두 화면이 서로 다른 사무실이 된다. 어디에 무엇이 놓이는지는
전부 맥이 계산해 `layout-*.json` 에 싣고(Swift `OfficeLayoutExport`), 이쪽은 받은 좌표를
화면 픽셀로 옮기기만 한다. 배율·바닥 명암·부서색·사람 외형처럼 되계산할 수 없는 값도 같이
실려 온다.

여기 남은 산술은 **타일 크기에 딸린 것들뿐**이다 — 이름표 크기와 문패 높이는 창 크기가
정해지기 전에는 값이 나오지 않아 내보낼 수가 없다. 그 계산에 쓰는 상수는 전부 `metrics`
에서 읽어 맥 앱과 같은 숫자를 본다.

## 파일

- `office.js` — 그리기 전부(바닥·벽·창문·가구·사람·라벨). 색 치환도 여기
- `live.js` — 백엔드에서 상태를 받아 오고 사람을 걷게 한다
- `serve.py` — 브라우저로 볼 때 쓰는 개발용 서버. 백엔드가 CORS 를 열지 않아 프록시가 필요하다
- `main.js` — 윈도우 앱의 껍데기. 서버 주소를 기억하고, 창과 같은 출처로 백엔드를 넘겨준다
- `setup.html` — 첫 실행 설정 화면(서버 주소·토큰)
- `package.json` — Electron 포장 설정. `build` 항목이 어느 파일을 설치본에 넣을지 정한다
- `sprites` — 맥 앱 리소스로 가는 심볼릭 링크(에셋을 복사하지 않는다). 설치본에는
  `extraResources` 로 실제 파일이 복사된다
