### [x] A. "왜 늦어져?" 병목 귀속 보고 워커 — 우선 (#467 머지 완료)

- **무엇**: "요즘 왜 느려", "뭐가 막혀 있어" 류 질문이 착지할 신규 워커. 원인을 우선순위로 귀속해

  ④없으면 "지연 없습니다"라고 명시적으로 닫기.
- **왜**: dispatcher 19종에 회사 현황·지연 귀속 착지점이 없다(2026-09-04 `router.module.ts` 실측).
  무한 되묻기의 원인이 워커 부재였던 계보(#261·#290)와 같은 자리.
- **전제**: 없음. 데이터 소스(agent_run 원장 · PreviewGate 카드 · 쿼터 에러)는 전부 기존 것.
- **완료 조건**: 신규 워커 체크리스트 13개(AGENTS.md §4 — `AGENT_TO_PROVIDER` · `/retry-run` switch ·
  `ResponseCode` 포함) + intent classifier 착지 예문 + `docs:check` + 실호출 검증 1건(Slack 실응답).
- **결과**: `DELAY_REPORT` 워커 신설 — #467 머지 (main `2311fc69`).
  판정은 결정론 조회(LLM 0회·원장 미기록), 승인 대기 > 진행 중 run > 미해소 실패 순으로 원인 하나 +

### [ ] B. BLOCK_REASON 상용구 사전 — 이유 + 해결 행동 (구현 완료 · 커밋/머지 대기)

- **무엇**: 실패·스킵·미연동 카드의 공통 포맷 사전. ①안 되는 진짜 이유 ②지어내지 않는다는 선언
  ③풀리면 무엇을 하는지. 쿼터 소진 · 연동 미설정 · 선행 산출물 부재 3부류부터.
- **전제**: A(#467)가 "이유 + 해결 행동" 문구를 이미 쓰고 있다 — 사전으로 뽑을 때 그 문구를
  출발점으로 삼고, A 의 미연동 판정이 message 문자열 매칭에 의존하는 한계도 함께 본다
  (`src/agent/delay-report/domain/attribute-delay.ts` 주석).
- **완료 조건**: 사전 1곳 정의 + A 워커와 기존 실패 카드 최소 1경로에 적용 + 3중 green.
- **결과**: 구현 완료, **아직 커밋/PR 전** (main 작업 트리에 미커밋 상태 — 브랜치로 옮겨 PR 올리면 닫힌다).
  사전은 `src/common/domain/block-reason.ts` 한 곳 — 부류 3종(QUOTA · INTEGRATION · PREREQUISITE)마다
  ②"지어내지 않는다" 선언 + ③해결 행동을 들고, ①이유는 호출부 문구를 그대로 쓴다.
  적용 2곳: (1) A 워커 — `attribute-delay.ts` 가 자체 신호 상수·상용구를 버리고 사전을 쓰고,
  `delay-report.formatter.ts` 의 조치 문구도 사전에서 가져온다. (2) 슬래시·버튼 실패 카드 공통 길목
  `slack-handler.helper.ts` 의 `toUserFacingErrorMessage`(호출 25곳 이상) — 알아본 부류에만 빠진 조각을
  채우고, 모르는 실패는 원문 그대로 둔다.
  덤: 사전이 PREREQUISITE 를 알아보면서 A 워커도 선행 산출물 부재를 별도 원인으로 귀속하게 됐다.
  같은 안내가 한 줄에 두 번 나오지 않도록 `statesRecoveryAlready` 로 ③ 중복을 막는다.
  게이트: `lint:check` · `test`(513 suite / 5,242) · `build` · `docs:check` 전부 green.
  실 렌더 문자열은 빌드 산출물로 4부류(미연동 · 쿼터 · 선행 부재 · 미분류)를 뽑아 눈으로 대조했다.
  **Slack 실멘션 왕복은 미검증** — A 와 같은 이유로 운영 백엔드(포트 3099) 재시작이 필요하다.
  한계: 판정이 여전히 message 문자열 매칭이다(원장·DomainException 에 errorCode 가 안 남는다).
  근거 파일·라인은 사전 상단 주석에 실측으로 적어 뒀고, 문구가 바뀌면 조용히 깨진다.
  자체 리뷰에서 3건을 잡아 고쳤다 — 쿼터 안내 중복 문장, 한 번만 쓰는 래퍼 함수, 조사 오류(`Notion가`).
